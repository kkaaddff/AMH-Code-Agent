## 核心组件分析

### 模型网关服务
模型网关服务是LLM集成的核心组件，负责封装各种模型的调用逻辑，支持多种API格式和响应解析。该服务提供了统一的接口来调用不同的LLM服务，同时处理请求载荷构建和响应解析。

```mermaid
classDiagram
class ModelGatewayService {
+modelConfig ModelGatewayConfig
+callModel(options ModelRequestOptions) Promise~ModelResponse~
+streamModel(options ModelRequestOptions, onChunk function) Promise~boolean~
+checkHealth() Promise~boolean~
+getConfig() ModelGatewayConfig
-buildRequestPayload(options ModelRequestOptions) Record~string, any~
-makeRequest(payload Record~string, any~) Promise~any~
-extractTextFromModelPayload(payload any) string | null
-extractUsageFromPayload(payload any) Record~string, any~ | undefined
}
class ModelGatewayConfig {
+baseURL string
+apiKey string
+model? string
+timeout? number
+temperature? number
+maxTokens? number
+topP? number
}
class ModelRequestOptions {
+prompt string
+model? string
+temperature? number
+maxTokens? number
+topP? number
+stream? boolean
+customPayload? Record~string, any~
}

+content string
+usage? Record~string, any~

}

```

### 前端工作流控制器
前端工作流控制器负责处理前端发起的LLM请求，支持流式响应（SSE）和工具调用。该控制器通过SSE协议与前端通信，实时发送消息、文本片段、流式结果和对话轮次等事件。

```mermaid
sequenceDiagram
participant Frontend as "前端"
participant Controller as "FrontendWorkflowController"
participant Service as "FrontendWorkflowService"
Frontend->>Controller : POST /code-agent/frontend-workflow
Controller->>Controller : 设置SSE响应头
Controller->>Service : 调用runWorkflow
Service->>Service : 执行工作流
Service->>Controller : onMessage回调
Controller->>Frontend : event : message
Service->>Controller : onText回调
Controller->>Frontend : event : text
Service->>Controller : onStreamResult回调
Controller->>Frontend : event : stream_result
Service->>Controller : onTurn回调
Controller->>Frontend : event : turn
Service->>Controller : 返回结果
Controller->>Frontend : event : complete
Controller->>Frontend : 结束连接
Note over Frontend,Controller : 支持客户端断开连接的优雅处理
```
