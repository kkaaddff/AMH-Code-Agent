## 工具系统架构

工具系统是Agent的核心组件，负责管理所有内置和外部工具的注册、调用和执行。系统通过`Tools`类统一管理所有工具实例，并提供类型安全的工具调用接口。

```mermaid
classDiagram
class Tools {
+tools : Record<string, Tool>
+constructor(tools : Tool[])
+get(toolName : string) : Tool
+length() : number
+invoke(toolName : string, args : string) : Promise<ToolResult>
+toLanguageV2Tools() : LanguageModelV2FunctionTool[]
}
class Tool {
+name : string
+description : string
+getDescription? : ({ params, cwd } : { params : z.output<TSchema>; cwd : string }) => string
+displayName? : string
+execute : (params : z.output<TSchema>) => Promise<ToolResult> | ToolResult
+approval? : ToolApprovalInfo
+parameters : TSchema
}
class ToolResult {
+llmContent : string | (TextPart | ImagePart)[]
+returnDisplay? : ReturnDisplay
+isError? : boolean
}
class ToolUse {
+name : string
+params : Record<string, any>
+callId : string
}
Tools "1" *-- "0..*" Tool : 包含
Tool --> ToolResult : 执行返回
ToolUse --> Tool : 调用
```

## 工具执行流程

工具执行流程是Agent与LLM交互的核心环节，从LLM输出解析工具调用到执行结果返回，形成完整的闭环。

```mermaid
sequenceDiagram
participant LLM as "LLM"
participant Loop as "循环处理器"
participant Tools as "工具管理器"
participant Tool as "具体工具"
LLM->>Loop : 输出工具调用
Loop->>Loop : 解析工具调用参数
Loop->>Loop : 调用onToolUse回调
Loop->>Loop : 请求工具审批
Loop->>Tools : 调用invoke方法
Tools->>Tool : 执行具体工具
Tool->>Tool : 执行业务逻辑
Tool-->>Tools : 返回执行结果
Tools-->>Loop : 返回工具结果
Loop->>Loop : 调用onToolResult回调
Loop->>Loop : 将结果添加到历史记录
Loop->>LLM : 发送工具执行结果
```

## 工具审批机制

工具审批机制是系统安全控制的核心，通过多层策略确保工具调用的安全性和可控性。

```mermaid
flowchart TD

CheckAutoApprove --> IsAutoApprove{"自动批准?"}

IsAutoApprove --> |否| CheckApprovalMode["检查审批模式"]
CheckApprovalMode --> IsYolo{"yolo模式?"}
IsYolo --> |是| ReturnTrue
IsYolo --> |否| GetTool["获取工具实例"]
GetTool --> CheckToolExist{"工具存在?"}

CheckToolExist --> |是| CheckReadCategory["检查读取类别"]

IsRead --> |是| ReturnTrue
IsRead --> |否| CheckNeedsApproval["检查是否需要审批"]
CheckNeedsApproval --> NeedsApproval{"需要审批?"}
NeedsApproval --> |否| ReturnTrue
NeedsApproval --> |是| CheckWriteCategory["检查写入类别"]
```

## 异步工具调用与超时管理

异步工具调用通过后端控制器中的pendingToolCalls映射表实现，结合60秒超时机制确保系统的响应性和稳定性。

```mermaid
sequenceDiagram
participant Frontend as "前端"
participant Backend as "后端控制器"
participant Agent as "Agent核心"
Frontend->>Backend : 发起SSE连接
Backend->>Backend : 初始化pendingToolCalls映射表
Backend->>Backend : 初始化sessionCallIds映射表
Agent->>Backend : 发起工具调用请求
Backend->>Frontend : 通过SSE发送工具调用事件
Frontend->>Backend : 执行工具并返回结果
Backend->>Backend : 在pendingToolCalls中查找对应Promise
Backend->>Backend : 根据结果resolve或reject Promise
Backend->>Agent : 返回工具执行结果
Backend->>Backend : 清理pendingToolCalls和sessionCallIds
Note over Backend,Frontend : 60秒超时机制
Backend->>Backend : 设置60秒超时定时器
Backend->>Agent : 超时后reject Promise并返回超时错误
```
